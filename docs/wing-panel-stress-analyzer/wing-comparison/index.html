Accuracy and limits

These are two executed benchmark cases, not an ML solver for arbitrary wings or angles. LWM is restricted to the authors' rectangular, uniform-section wing context; Reynolds number is not a model input. This comparison does not validate a low-Reynolds-number 900 mm foam wing, stall, structural response, viscous drag or flight safety. Panel assumes attached low-Mach flow. No CFD is solved here.

Panel uses analytic closed-trailing-edge NACA geometry and our rounded-tip model. LWM uses the authors' sampled section geometry and implicit tip representation. These geometries are comparable, but not identical.

Help · a solved comparison

1. Select NACA 0012 at 8.85°. Inspect η = 0.05, then η = 0.9883. The tip pressure shape is where panel and experiment differ most visibly.

2. Compare the 672 and 1152 panel meshes. The full-wing CL changes by about 0.11%, while the remaining experimental error is about 3.3%; increasing panel count alone does not remove model-form and geometry differences.

3. Select NACA 0015 and read the tunnel-correction warning. Compare actual experimental markers with both curves. CL agreement alone does not guarantee local Cp accuracy.

Re-solve panel runs the current bundled solver in your browser for the selected fixed reference case. LWM remains a recorded, unconditioned inference executed on Unity; changing the panel mesh does not re-run ML. Recorded and fresh panel results are labelled explicitly.

Sources and execution

Measurements are published reference data. Blue curves are our panel solves; orange curves are our execution of the authors' pretrained model. No measurements were used to condition these test predictions. Original model source and weights remain in the authors' repository.
