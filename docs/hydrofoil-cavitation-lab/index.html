Inputs & model limits

σ = (p∞ − pv)/(½ρU²). Pressure is absolute. The selected input definition controls the calculation; cavity length and shape are outputs. Fresh-water properties use IAPWS.

A fully wetted hydrofoil is a valid no-cavity result. An unsupported disk target is outside the chosen model’s admitted range; it does not establish that the physical flow has no cavity. No accepted cavity is reported after a failed calculation.

The disk BEM has an artificial rear image disk; its cylinder option requires dry containment. Analytical cone and cylinder cases use source-limited drag and main-envelope estimates with finite endpoints, not an exact physical closure.
