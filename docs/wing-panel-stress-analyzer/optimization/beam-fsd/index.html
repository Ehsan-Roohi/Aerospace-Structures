Fully Stressed Tapered Beam

beam-fsd 0.1.1
Scope. This page takes the prismatic beam you sized yourself, lets the depth (or the tube wall) follow the bending-moment diagram through the fully stressed design (FSD) iteration, and shows what the taper saves in mass and what it costs in stiffness. Model: Euler-Bernoulli beam, linear elastic, small deflection, bending about one axis, no shear deformation, no lateral or local buckling, no fatigue, no stress concentration at the steps. Every design shown is re-solved from scratch with the exact finite element solver and all constraints are re-checked; nothing here is a certified strength or safety statement, and the page is independent of the Wing AeroStruct solver.

How it works

Model
The beam is meshed with 2-node Hermite cubic Euler-Bernoulli finite elements (FE): one element per segment, with extra nodes at every load position and at the supports, and each element carries its own bending stiffness EI. For a beam with piecewise constant EI, point loads and uniform loads this element gives the exact nodal deflections, so the bending moment M(x) and shear V(x) recovered from the element end forces are exact everywhere. The bending stress at the extreme fibre is sigma = |M| c / I and the stress utilization is U = sigma FS / sigma_allow, with FS the factor of safety. The deflection utilization is max |v| divided by L / k.
Fully stressed design iteration
  1. Prismatic start. One uniform depth h (or wall t) is chosen so that the largest bending moment reaches exactly the allowable stress divided by FS. This is the design you would make by hand.
  2. Resize every segment. The governing section of a segment is the point with the largest |M| in it (an end, or the point where the shear is zero under a uniform load). With U computed there, the rectangle depth is updated as h_new = h sqrt(U), because the bending stress scales with 1/h^2 at fixed width. For the tube the wall is updated by solving I(t_new) = I(t) U exactly, with t_min <= t <= D / 2. A segment that wants to be thinner than the minimum stays at the minimum.
  3. Repeat until max |U - 1| < 0.001 on every segment not at the minimum, or 60 iterations. For a cantilever or a simply supported beam the moment diagram does not depend on the stiffness, so the first resize already is the fixed point. For the propped cantilever (statically indeterminate) the moments move toward the stiffer parts after each resize, so the loop runs many times and the design drifts toward a nearly statically determinate one with a very thin region near the inflection point. From the second pass the update uses h_new = h U^(p/2) with the exponent p chosen above; p = 1 is the textbook stress-ratio rule, p = 1.5 reaches the same fixed point in fewer passes.
  4. Deflection limit. Tapering removes material where the moment is small, which also removes stiffness, so the fully stressed beam deflects more than the prismatic one. If it exceeds L / k, the whole profile is multiplied by one factor s, found by bisection, until max |v| equals L / k exactly. The prismatic beam gets the same treatment so the two can be compared under identical limits. Uniform scaling is a simple repair, not the minimum-mass design under a deflection limit.
  5. Verify. Each design is rebuilt from its numbers, re-solved with the plain solver and re-checked (stress in every segment, deflection, minimum dimension) before anything is shown.
Classical results
Cantilever with a tip load and a rectangle of fixed width: h(x) = h_root sqrt(1 - x / L), Galileo's parabolic beam of uniform strength (1638). The continuous profile has exactly 2/3 of the prismatic mass and twice its tip deflection. Simply supported beam under a uniform load, fixed width: h(x) = h_mid sqrt(4 x (L - x)) / L; the integral of sqrt(x (L - x)) from 0 to L is pi L^2 / 8, so the mass ratio is pi / 4 = 0.785, and the midspan deflection ratio is (6 pi - 12) / 5 = 1.370. For a thin-walled tube of fixed outer diameter the section modulus is proportional to the wall, so t(x) follows |M(x)|: mass ratio 1/2 for the cantilever with tip load (moment triangle), 2/3 for the simply supported beam under uniform load (moment parabola). A stepped design in which each step is sized for the largest moment inside it is always a little heavier than the continuous profile and approaches it as N grows (the difference is of order 1 / N); refine N and watch the numbers move.
Limitations
Only the bending stress at the extreme fibre is checked. Shear stress, stress concentrations at the steps, lateral-torsional and local buckling, fatigue, and manufacturing constraints are not considered. The linear taper option changes only the drawing (the smooth profile through the segment midpoints has the same volume as the stepped one for the rectangle, and nearly the same for the tube); the analysis always uses one depth per segment. Material cards are representative educational values, not certified allowables. Results are not a substitute for a design code check.
