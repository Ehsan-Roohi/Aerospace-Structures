## Original chart assumptions

- funding_scopes: the Wright bar uses $1,000 as a displayed upper bound for a **less-than-$1,000 recollection**, not an exact value. [Fred C. Kelly's retrospective account](https://www.wright-brothers.org/History_Wing/Aviations_Attic/They_Wouldnt_Believe/They_Wouldnt_Believe_the_Wrights_Had_Flown.htm). Langley's bars show $50,000 + $20,000 allocated funds, from the [1928 Smithsonian account, Appendix II](https://repository.si.edu/server/api/core/bitstreams/b978cc0e-1c63-40d5-9b9c-5592ade4c3f5/content). Accounting scopes differ; no efficiency ratio is computed.
- army_purchase_price: $25,000 base plus $5,000 speed bonus, from the [Smithsonian Military Flyer record](https://www.si.edu/object/1909-wright-military-flyer%3Anasm_A19120001000).
- manufacturing_sequence: original instructional interpretation, not an archived factory floor plan or recovered process drawing.
