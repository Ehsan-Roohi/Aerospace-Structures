Purpose and model

Compute the two-dimensional pressure force on a NACA 2412 airfoil. Question 1 uses continuous geometry and pressure functions. Question 2 uses 101 supplied stations to compute the same force by summing straight-panel contributions. No derivation of the pressure-force formulas is required.

Model statement. The supplied pressure distribution is an instructional surrogate for attached flow at α = 5°. It gives a plausible suction peak and lift trend, but it is not measured pressure-tap data or a universal NACA 2412 pressure law. Only pressure forces are included: the computed drag is pressure drag, not total drag.

Numerical-integration guide for 1c

Why the leading edge needs care. The thickness slope contains 1/√X, which is undefined at X = 0. The area under it is finite, but a numerical routine must not evaluate that raw slope at X = 0.

Recommended route. Set X = s2, so dX = 2s ds and 0 ≤ s ≤ 1. This places more X-points near the leading edge and removes the endpoint difficulty. Define the transformed normal and axial integrands as:

gN(s)=2s[Cp,l(s2)−Cp,u(s2)]
gA(s)=2s[Cp,u(s2)Yu′(s2)−Cp,l(s2)Yl′(s2)]

Here a prime means dY/dX, evaluated at X = s2. At the single endpoint s = 0, use the finite limits gN(0) = 0 and gA(0) = 10t(0.2969) = 0.35628; do not calculate 0 × ∞.

Compute and check. Use the composite trapezoidal rule for each g on sj = j/N, j = 0, ..., N:

I[g]≈1N(12g(0)+∑j=1N−1g(jN)+12g(1))

Here I[g] means the integral of g from s = 0 to 1. Apply the rule once with N = 1000 and again with N = 2000. Compare the two CN values and the two CA values. Report both discretizations and their absolute differences. A difference below 10−4 for each coefficient is adequate for this assignment.

What is adaptive quadrature? It is software that estimates integration error and automatically uses smaller intervals where a function changes rapidly. You are not asked to implement it. If you choose a library such as scipy.integrate.quad, apply it to gN and gA on 0 ≤ s ≤ 1, state the requested tolerance, and repeat with a tighter tolerance to demonstrate convergence.
