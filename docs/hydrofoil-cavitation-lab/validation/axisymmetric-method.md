# Axisymmetric research module: equations and verification

Version `0.1.0-research`, 30 October 2026.

This module solves **three-dimensional, fully wetted, axisymmetric potential flow** around a sphere or prolate spheroid. A meridional segment represents an entire conical surface band; its azimuthal influence is integrated analytically. It does not rotate a two-dimensional airfoil solution. The numerical equations contain no analytic sphere or spheroid pressure values; those values are evaluated after the solve for comparison only.

It does **not** yet solve an axisymmetric cavity free boundary. The cavitation output is the fully wetted Bernoulli pressure criterion, not a cavity length, cavity shape or experimental inception prediction.

## Boundary integral

Let the meridian run from the upstream to downstream pole, with tangent `t=(t_x,t_r)` and outward normal `n=(-t_r,t_x)`. The full surface is generated by revolution about `x`. Lengths are normalized by the axial semilength during assembly.

With an outward-positive source density, the disturbance potential and velocity are

\[
\phi(P)=-\frac{1}{4\pi}\int_S\frac{\sigma(Q)}{|P-Q|}\,dS_Q,
\qquad
\boldsymbol v(P)=U\boldsymbol e_x+\frac{1}{4\pi}\int_S\sigma(Q)\frac{P-Q}{|P-Q|^3}\,dS_Q.
\]

The exterior trace satisfies

\[
\frac{\sigma(P)}2+\operatorname{PV}\int_S
\frac{\sigma(Q)\,\boldsymbol n(P)\cdot(P-Q)}{4\pi|P-Q|^3}\,dS_Q
=-U n_x(P).
\]

The `+1/2` sign corresponds to the potential sign above. Changing the potential convention requires changing both kernel and jump. The sphere and exterior-field checks test this sign independently.

For a source ring at `(x',r')`, define

\[
D=(x-x')^2+(r+r')^2,\quad B=(x-x')^2+(r-r')^2,
\quad m=1-B/D.
\]

The ring velocity per unit source density and meridional length is

\[
v_x=\frac{r'(x-x')E(m)}{\pi\sqrt D\,B},
\qquad
v_r=\frac{r'}{\pi\sqrt D}
\left[\frac{K(m)-E(m)}{2r}+\frac{(r-r')E(m)}B\right].
\]

Complete elliptic integrals are evaluated by the arithmetic-geometric mean. The complementary parameter `B/D` is supplied directly, avoiding loss of precision from `1-m` near a coincident ring. At `r=0`, the axial limiting expression is used and radial velocity is zero.

Constant source density is assigned to each straight meridional segment. Off-diagonal meridional integrals use Gauss-Legendre quadrature. The self normal kernel is logarithmically singular. The self tangent kernel has an odd principal-value term; paired integration about the midpoint cancels that term before accumulation. A squared local coordinate resolves the remaining logarithm. The normal jump is added once, only to the normal row.

After solving, the tangent velocity gives `Cp=1-(v_t/U)^2` and `p=p_inf+0.5*rho*U^2*Cp`. No Cp values are clipped or replaced by reference values.

## Independent controls

1. Direct three-dimensional azimuthal quadrature checks the ring velocity without using elliptic functions, including a near-ring case and an on-axis case.
2. A sphere has `v_t/U=1.5 sin(theta)` and `Cp=1-2.25 sin(theta)^2`.
3. A prolate spheroid with semiaxes `a,b,b` has

\[
L_x=\frac{1-e^2}{e^3}[\operatorname{atanh}(e)-e],
\quad e^2=1-b^2/a^2,
\quad \frac{v_t}{U}=\frac{\sin\theta}{(1-L_x)\sqrt{\sin^2\theta+(b/a)^2\cos^2\theta}}.
\]

The test independently recomputes `Lx` from its depolarization integral by Simpson quadrature, rather than trusting the kernel's closed-form reference field. The sphere limit is `Lx=1/3`.

4. The sphere velocity at four off-surface points is compared with the exact three-dimensional dipole field. These are separate field points, not values fitted at the collocation locations.
5. Normal velocity is reintegrated at one-quarter and three-quarters of **every** band at a different quadrature order. This reveals the actual discretization error hidden by an algebraically exact collocation solve.
6. Net source flux, fore-aft antisymmetry, zero axial pressure force, dimensional/speed invariance, quadrature refinement and unsupported-input rejection are checked.

All samples, including the first and last polar bands, are retained. The final script has 61 checks and writes the complete profiles to `axisymmetric-verification.json`.

This is approximately first-order convergence, consistent with constant-density, piecewise conical bands. The default 64-band result is useful for a quick research preview; 128 or 256 bands improve accuracy. Timing on the current Node runtime is below a second even at 512 bands, but browser/device timing is separate.

The maximum **collocation** normal residual is about machine precision. It must never be presented as the maximum residual over the whole surface. Likewise, a near-zero axial pressure-force diagnostic is not a prediction of viscous drag.

The initial N256 exterior-velocity target of `0.0005 U` failed: error `0.000699 U`. The same unchanged bound is met at N512: `0.000353 U`. The initial exploratory requirement that every doubling reduce this error by a factor below 0.6 also failed on the coarsest 16-to-32 transition. Both original failures remain in `axisymmetric-initial-gates-failed.json`; the final report does not claim they passed. All measured errors and the monotonically decreasing sequence remain visible.

## Cavitation interpretation

The number `sigma=(p_inf-p_v)/(0.5*rho*U^2)` is compared with `-min(Cp)` from the **fully wetted** solution. If `Cp<-sigma`, that solution predicts pressure below vapour pressure and is no longer a physical developed-flow description there. No negative-pressure region is relabelled as an already solved cavity. Viscosity, nuclei, surface condition, turbulence, tunnel blockage and hysteresis can move experimental inception and separation.

For a developed axisymmetric cavity, additional unknown geometry must satisfy no penetration, constant cavity pressure and an explicit detachment/closure model, plus any tunnel boundary conditions. A sphere's smooth detachment location is an unknown; disk-edge detachment is geometrically prescribed. Partial cavities reattach on the body; supercavities extend beyond it. These are distinct free-boundary problems, not options produced by the fully wetted source solution alone.

## Source context

- [Alavi and Roohi, *Cavitation review, Part I*, Physics Reports1197(2026)1-146](https://doi.org/10.1016/j.physrep.2026.06.004). The supplied review was read locally. Pages119 and121 discuss Brennen's axisymmetric disk/sphere cavity calculation; Fig133 compares calculated and measured sphere separation. The review is context and a reference map, not a complete matched BEM input/validation dataset.
- [Brennen, *A numerical solution of axisymmetric cavity flows*, JFM37(1969)671-688](https://doi.org/10.1017/S0022112069000802); [Caltech author record](https://authors.library.caltech.edu/records/46gc9-rw507). This concerns fully developed disk/sphere cavities in solid-wall tunnels, with choking and viscous separation effects. A future comparison must match tunnel size, detachment and closure; no agreement with those cavity experiments is claimed here.
- [Symscape, *Potential Flow Around an Ellipsoid*](https://www.symscape.com/examples/panel/potential_flow_ellipsoid.html), an implementation-author comparison with the analytic ellipsoid velocity expression. The analytic formula, not that vendor's computed results, is used as the independent fully wetted control.
- [Southampton thesis, section3.9](https://eprints.soton.ac.uk/459286/1/166309.pdf), axisymmetric ring Green function reduction; the implementation above was derived from the 3-D source Green function and tested independently by direct ring integration.

## Run and API

Run `node docs/hydrofoil-cavitation-lab/validation/axisymmetric-verify.cjs` from the repository root.

Browser global `AxisymmetricBEM`; CommonJS `require('../axisymmetric.js')`. `solve({geometry:'sphere'|'prolate',radius,length,panels,speed,density,ambientPressure,vapourPressure,yawDeg:0,incidenceDeg:0})` returns node coordinates, centroid Cp/pressure, source density, collocation diagnostics and an explicitly limited inception indicator. Dimensions are metres, speed is m/s and pressures are absolute Pa. `length` is `2*radius` for a sphere. `evaluateVelocity(result,{x,r})` evaluates the off-surface field. Nonzero incidence/yaw and developed-cavity requests are rejected.
