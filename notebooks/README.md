### Lecture 02 — Finite Wings, Geometry and Load Paths

[![Open Lecture 02 in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Ehsan-Roohi/Aerospace-Structures/blob/main/notebooks/MIE446_Lecture_02_Finite_Wings_and_Load_Paths.ipynb)

[View the notebook](MIE446_Lecture_02_Finite_Wings_and_Load_Paths.ipynb). This 75-minute lesson connects span, chord, taper, aspect ratio, sweep and dihedral to induced drag, spanwise load distributions, structural load paths and cantilever root reactions. Students predict, change simple form inputs, verify equations and audit an AI-generated claim. Optional derivations are after-class material. No CAD installation is required.

## Recommended Colab workflow

1. Open the notebook using its **Open in Colab** button.
2. In Colab, choose **File → Save a copy in Drive** before changing any inputs.
3. Run the setup cell first. Do not continue if the environment check fails.
4. Complete each prediction before running the cell that reveals the result.
5. Change only the clearly marked student inputs unless an assignment explicitly authorizes code modification.
6. Rerun every affected downstream cell after changing an earlier input.
7. Keep the saved notebook and any downloaded evidence files with the assignment or team record.

## What students are responsible for

A green check or successful run is evidence, not proof that an engineering conclusion is correct. Students remain responsible for:

- the physical system and sign convention;
- assumptions and limits of the selected model;
- units, equilibrium, trends and limiting-case checks;
- interpretation of plots and automated validation;
- independent verification of material AI-assisted work;
- a clear statement of confidence and limitations.

Use the course evidence language:

> **Claim — Evidence — Check — Confidence — Limitation**

## Troubleshooting

- If a notebook opens in GitHub instead of Colab, return here and use the Colab badge.
- If the runtime becomes inconsistent, choose **Runtime → Disconnect and delete runtime**, reopen the released link and run from the first cell.
- If an error remains, preserve the complete error text and identify the notebook, step, team or revision, and the input change that preceded it.
- Canvas is authoritative for assignments, deadlines, approved versions and help channels.
