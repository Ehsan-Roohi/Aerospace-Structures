# What the experimental differences establish

There is no primary-source basis here for a universal "4-13% is normal" rule. Our four Waid forward-length differences and smaller radius differences are useful limited experimental comparisons, but their numerical mesh checks and their physical accuracy are separate questions. The 64-to-128 mesh change is below 0.05% in these dimensions; it does not explain length differences reaching 12.5%. Facility, gravity, ventilation, sting and downstream closure remain unmatched.

# Feasible hydrofoil experimental benchmark

The original **Uhlman-Jiang1977, MIT83481-2 / DTICADA045767** report has now been recovered and inspected. This is the source behind the review's Fig139, via Lemonnier-Rowe's Fig9. Primary report PDFp12/reportp2 specifies a **parabolic suction side and flat pressure side**, t/c=.06, chord4in, span19.75in, mounted vertically in a20in-square tunnel. It is neither a circular arc nor NACA0006. The reconstructed upper curve is z/c=4(.06)(x/c)(1-x/c), derived from the stated parabola, mid-chord thickness and endpoints rather than a printed coordinate table.

**Choose alpha4deg or6deg and short cavities first.** Report PDFpp17-20/reportpp7-10 explicitly says the alpha2deg theories underpredict length, with possible midchord cavitation, and flags instability for L/c>.75. Therefore the review's alpha2deg figure should not become a convenient acceptance target for a leading-edge-only model.

Primary Fig3, PDFp24/reportp14, alpha4deg, has **open triangles based on actual measured cavity pressure** and filled triangles based on vapor pressure. These must remain separate. All five resolved open markers are read in `uhlman-alpha4-open-points.json` and CSV, including the L/c approximately.773 point above the stated instability threshold. The raw plotted alpha/sigma ratio is retained; converted sigma assumes alpha in radians and is explicitly marked as an inference. Reading bounds are +/-0.001 in the ratio and +/-0.01 in L/c, not experimental confidence intervals.

The expanded `uhlman-alpha4-all-markers.json`/CSV retains those five open markers, eight resolved filled vapor-pressure markers, and one additional overlapped marker whose fill/pressure basis cannot be assigned reliably. `uhlman-alpha4-experimental-benchmark.png` and SVG show only these measurements, in both original ratio coordinates and converted sigma coordinates; the marks have reading bounds, not measurement confidence intervals. All high-length points are retained. No current-solver curve is displayed, and no theoretical curve is reconstructed from the overlapping scan strokes.

Per-point speed and Reynolds number are not tabulated: the report varied speed to acquire each data set. Its maximum facility speed9.1m/s is not each point's velocity. Cavity pressure was measured at a tap nearx/c=.17 when covered. The report also corrected lift using theoretical fully-wetted lift because of load-cell sensitivity; cavity length is a cleaner independent observable than those corrected forces.

Before calling this matched validation, the solver must use the actual custom profile, declared sharp-edge detachment and closure/recovery, measured-Pc sigma, and either tunnel modeling or an explicit facility qualification. No substituted NACA calculation was run. **Hydrofoil experimental validation is not completed.**

A second modern Cp benchmark is available in the primary SMP2009 PDFp3 Fig2: NACA66(mod)-312 a=.8, alpha6deg, Re750000, sigmaV1.495, with measured pressures from Leroux2003. Exact modified coordinates and original tunnel/closure details still need retrieval; the generic name "NACA66" is insufficient.

The source report is linked rather than redistributed. Numerical reading coordinates, provenance and citations can be reviewed separately.
