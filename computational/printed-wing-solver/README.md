A transparent structural model of the **as-printed** MIE 446 semi-wing: the PLA shell, solid nose and trailing-edge strip, printed rod sleeves, carbon rods, ribs and module seams generated by the course CAD code (`mie446_wing` v1.1.1).

## What it computes

| Step | Method | Independent check |
|---|---|---|
| Cross-section at any span station | Same NACA equations and cavity rule as the CAD code | Printed mass 241.6 g vs 240.8 g from CadQuery; cut-section areas within 1.5 % |
| Area, centroid, second moments | Exact polygon integration, modulus-weighted; slip-fit rods add only their own EI | Closed-form rectangle-with-hole test |
| Torsion constant, shear centre, shear stress | 2-D finite-element warping analysis (`sectionproperties`) | Bredt–Batho thin-wall J (within 4–10 %); thin tube closed form; shear-resultant and sign-convention test |
| Loads | Schrenk / elliptic / planform / uniform / tip lift × load factor, inertia relief; or a tip force | Root reactions equal the applied resultants to machine precision |
| Deflection and twist | Direct integration of M/EI and T/GJ, dry seams as rotational springs | 1-D Hermite beam FEM (agreement < 0.1 %); PL³/3EI and spring closed forms |
| Natural frequencies | 1-D FEM with consistent mass, lumped rib, cap and sensor masses | Uniform-cantilever frequency |
| Screening checks | PLA tension/compression/shear, skin buckling (flat plate vs NASA SP-8007 knocked-down cylinder), rod bending, rib bearing and dowel shear at dry seams, epoxied-seam joint, deflection, twist | Hand checks in the notebook |

Units are mm, N, MPa and g.

## Baseline findings (class baseline, PLA upright card, hobby-grade rods, dry seams)

* Two slip-fit 4 mm rods supply only about 2 % of the root bending stiffness; the PLA skin carries the bending.
* Dry module seams roughly halve the tip stiffness (0.38 versus 0.85 N/mm with epoxied seams), and rod clearance can add a dead band of about 3 mm at the tip.
* The governing screen is **compression buckling of the upper skin**, not material strength. A 10 N tip force exceeds the buckling screen (U ≈ 1.4) and brings the hobby-grade rods at the root-side seam close to their bending strength (U ≈ 0.9).

Material cards are deliberately labelled placeholders; replace them with coupon data.

## Use

```bash
pip install -r requirements.txt
python -m pytest -q tests          # 22 verification tests, about 45 s
python build_notebook.py           # rebuilds notebooks/MIE446_Printed_Wing_Structural_Solver.ipynb (add --execute to run it)
```

```python
import printed_wing_solver as pws

geom = pws.WingGeometry(naca="2412", semi_span_mm=450, root_chord_mm=160, tip_chord_mm=100)
res = pws.solve(geom, pws.PLA_UPRIGHT, pws.ROD_HOBBY,
                pws.Assembly(rods_bonded=False, seams_bonded=False),
                pws.LoadCase(kind="tip", tip_force_N=10.0, factor_of_safety=1.0))
print(res.summary())
for row in res.check_table():
    print(row["check"], row["utilization"], row["status"])
```

## Wing Lab: the same solver as a 3-D browser app

Start with **Start here · learn**: six guided steps explain the physical parts, load path, bending, torsion, connections and interpretation. **Complete wing**, **Inside wing**, **Ribs only**, and **Rods & sleeves** show the selected project geometry without changing the structural calculation. Ribs R1–R7 in the baseline are physical CAD ribs, not the seven numerical analysis sections. Separate stringers and full-height spar webs are not part of this printed design.

The 2 N / 4 N load exercise and the chordwise force-position exercise connect theory to calculated numbers. Each step teaches the idea before asking a question; **Check my answer** provides feedback. **Edit inputs** opens the original study tree and property controls. All model checks remain educational screens, not physical validation or flight approval.

UI regression checks: `node computational/printed-wing-solver/web/test_teaching_ui.mjs` (from the repository root). These check the generated page and geometry figures; they do not substitute for an interactive browser test.

[Launch Wing Lab online](https://ehsan-roohi.github.io/Aerospace-Structures/wing-lab.html) — no download or installation required. Wing Lab is a single-file browser app in the style of an FEA package: study tree, property panel, 3-D viewport with stress, displacement and factor-of-safety fringe plots, deformed shape, exploded and see-through views, section clipping, animated modes, diagrams, checks, a joint comparison, a predict-then-run exercise and a design challenge. Internet access is required to load three.js from a CDN. Alternatively, download [`docs/wing-lab.html`](../../docs/wing-lab.html) and open it in a modern browser.

Its engine, [`web/engine.js`](web/engine.js), is a JavaScript port of `printed_wing_solver.py`. The shell section is meshed with a mapped ring of triangles instead of `sectionproperties`; everything else follows the Python code line by line. The port is checked against the Python solver:

```bash
python web/export_reference.py     # five reference cases from the Python solver
node web/verify_engine.mjs         # 238 comparisons; tip deflection within 0.1 %, frequencies within 0.02 %
python web/build_wing_lab.py       # inlines the engine into docs/wing-lab.html
```

## Limits

Linear elastic, small deflection, plane sections between ribs, one spanwise modulus for printed PLA, uncoupled bending and torsion dynamics, no post-buckling, stress concentrations, shear lag or creep. The dry-seam spring (rods bending over an effective free length) and the clearance dead band are estimates with uncertain inputs. This is a teaching analysis: it does not authorise loading, flying or testing a student wing.
