# Printing examples

This folder contains an archival G-code file from a successful July 2026 workshop print. It is published so students can inspect the header, provenance, printer identifier, and structure of a real OrcaSlicer output.

## Do not print the sample

`successful-july-2026-k2pro-orcaslicer.gcode` is **not approved for the Fall 2026 MIE 446 wing project**. G-code is specific to the original geometry, machine, nozzle, material profile, firmware assumptions, and slicer settings. Do not run it, rename it as a team submission, hand-edit it, or use AI to adapt it.

Generate a new file in OrcaSlicer from the team's checked geometry and the current validated Creality K2 Pro / 0.4 mm course profile. Inspect every layer and complete the release checklist before copying the new `.gcode` file to USB.
