    Design lab · place ribs, predict, compare

    Change one thing at a time. First predict what will change; then edit the wing and compare it with your saved baseline. Positions are measured in millimetres from the root, not from the previous rib.

    What should adding a rib do?

    A rib preserves the airfoil shape and supports the skin. An extra rib adds mass and can shorten a skin bay. It does not create lift. For a fixed tip force P, equilibrium still gives:

    |V(0)| = |P|   ·   |M(0)| = |P|L
    Skin bay length = distance between neighbouring supports

    This beam model includes rib mass, its flight inertia relief, modal mass and rib spacing in an approximate skin-buckling screen. It does not add a rib's local diaphragm stiffness to distributed EI or GJ. Under a fixed tip force, rib changes alone therefore leave static bending and twist unchanged. Real ribs can prevent local distortion that this model cannot resolve.

    For flight loading, the specified aircraft mass and load factor set gross lift. Added rib mass changes the downward inertia-relief loads when that option is enabled; gross lift does not automatically increase. Update aircraft mass separately if that is your intended experiment.

    The 2 N experiment uses your current geometry with an upward tip force at 0.30c; it replaces the current load case. Baselines and edits are kept only in this open browser session.

    Explain the evidence

    1. What changed, by how much?
    2. Which quantities stayed the same, and why?
    3. Did mass increase without a useful change in the longest bay?
    4. Is the conclusion a result of physics, or a limitation of this model?
