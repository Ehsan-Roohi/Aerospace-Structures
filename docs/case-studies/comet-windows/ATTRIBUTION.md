## Original educational diagrams

The seven other PNGs are generated by [the Python source](../../../scripts/build_comet_case_study.py): pressure load paths, cutout details, historical-estimate bars, analytical Kirsch fields, ellipse radius effects, conceptual fatigue sequence and historical cycle counts. The plots distinguish actual reported values from assumed inputs and idealized models. They are not original investigation images or aircraft FE results.
